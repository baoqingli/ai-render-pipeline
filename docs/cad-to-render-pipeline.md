## 一句话方案

做一个**"CAD 到空间效果图"的自动流水线**：

```
DXF/DWG
  → 自动解析
  → 结构化场景 JSON
  → Blender 自动建白模
  → 生成深度图 / 线稿图
  → AI 渲染
  → 批量输出
```

---

## 最小知识集

不用懂"墙体、层高、门窗规范"这些业务概念本身，只要把它们当成**字段**：

| 字段 | 含义 |
| --- | --- |
| `wall` | 墙线 / 墙面区域 |
| `door` | 门洞 |
| `window` | 窗洞 |
| `floor_height` | 层高 |
| `wall_thickness` | 墙厚 |

程序里只需要这些数据，不需要先会画图。

## 推荐实施方案

### 1. 做"受限输入"，不要做"任意 CAD 通吃"

这是最关键的工程判断。不要一开始做"上传任何图纸都能自动识别"，那会卡死。
应该先规定一种支持格式：

- 优先：**DXF**
- 图层命名尽量规范
- 门窗最好是标准块（Block）
- 层高可以用户填一个默认值
- 墙厚可以默认一个值，比如 `200mm`

这一步不是让用户配合你，而是让系统先支持一种**可控输入**。

### 2. 让程序自动做"CAD 预处理"

不用手工理解图纸，程序做三件事：

**（1）过滤无关内容**

比如尺寸线、文字、标注、轴网先丢掉。

**（2）识别基础元素**

- 线段、折线
- 图层名
- 块引用
- 文本标注

**（3）转成统一 JSON**

这一步最重要。后面所有模块都只吃 JSON。

```json
{
  "unit": "mm",
  "floor_height": 2800,
  "wall_thickness": 200,
  "walls": [],
  "doors": [],
  "windows": [],
  "rooms": []
}
```

### 3. 用 AI Agent 辅助"解析和修复"，但不要让 AI 直接画图

AI 最适合做两类事：

**A. 帮你理解 CAD 文件**

- 哪些层像墙体层
- 哪些块像门窗
- 哪些字段缺失
- 当前图纸适不适合自动处理

可以做成一个 **CAD 解析 Agent**，读取 DXF 元数据后给出建议：

- "WALL 图层存在，可信"
- "门窗块命名不规范，建议人工确认一次"
- "层高缺失，使用默认 2800"

**B. 帮你生成解析脚本**

让 AI 帮忙写：

- DXF 解析脚本
- 规则清洗脚本
- Blender 建模脚本
- ComfyUI 工作流配置

但最终线上执行的必须是**确定性代码**，不是让 LLM 在线临场发挥。

### 4. 白模生成全部自动化

用 **Blender Python API** 做。程序做这些事：

- 根据 JSON 挤出墙体
- 根据门窗数据切洞
- 放地面和天花
- 放一些简单体块家具
- 自动布相机
- 自动渲深度图和线稿图

不需要懂 Blender 交互，只需要写脚本驱动它。

建议运行方式（批处理，不依赖 GUI）：

```bash
blender --background --python generate_scene.py
```

### 5. AI 渲染只做"风格化"，不做结构判断

结构已经由白模保证了。AI 的任务只是：

- 变材质
- 变光照
- 变软装风格
- 变整体氛围

推荐组合：

- **ComfyUI**
- **SDXL** 或类似模型
- **ControlNet Depth**
- **ControlNet Lineart**
- **IP-Adapter**

可以理解为：

```
白模 = 骨架
AI   = 化妆和装修
```

## 程序员视角的系统架构

### 服务拆分

| 服务 | 职责 |
| --- | --- |
| **1. API 服务** | 上传文件 / 创建任务 / 查询进度 / 下载结果 |
| **2. CAD 解析服务** | DXF 读取 / 图层、块分析 / 输出结构 JSON |
| **3. 白模生成服务** | Blender headless / 输出深度图、白模图、视角图 |
| **4. AI 渲染服务** | ComfyUI 推理 / 生成多风格版本 |
| **5. 任务队列** | Redis + Celery/RQ / 管批处理和失败重试 |

## 最小可行版本（MVP）

### MVP 输入

- 一个 DXF
- 一个默认层高
- 一个默认墙厚
- 一个风格模板
- 可选参考图

### MVP 输出

- 3 到 5 张效果图
- 支持批量风格变体
- 支持重跑某一张

### MVP 先不做

- 全自动识别所有 CAD 规范
- 复杂人工修图
- 自动精准质检
- 多人协同编辑

## AI Agent 的正确用法

把 AI Agent 放在这几个地方：

### 1. 生成代码

让 Agent 帮忙写：

- DXF 解析脚本
- Blender 脚本
- ComfyUI API 调用
- 前后端接口

### 2. 生成规则

让 Agent 根据样本图纸总结：

- 哪些图层像墙
- 哪些块像门窗
- 哪些文件需要人工确认

### 3. 处理异常样本

当解析失败时，让 Agent 输出：

- 问题原因
- 建议修复动作
- 是否可跳过

### 4. 批量生成渲染提示词

让 Agent 把用户选的风格，拼成稳定 prompt。

## 分阶段落地路线

### 第一阶段：先不碰 CAD 智能识别

直接做：

```
人工准备 DXF / 结构化输入
  → Blender 生成白模
  → AI 渲染
```

**目的：先把出图链路跑通。**

### 第二阶段：做 DXF 自动解析

加入：

- 图层识别
- 门窗块识别
- 墙体提取
- 层高默认值

### 第三阶段：加 AI Agent 做异常处理

让 Agent 帮忙处理：

- 图层不规范
- 门窗识别失败
- 层高缺失
- 墙厚无法判断

---

## 结论

对程序员背景来说，最稳的做法不是从设计知识补起，而是：

> **把设计问题转成数据问题，把 CAD 问题转成解析问题，把渲染问题转成任务队列问题。**

分工：

- **你**负责程序
- **AI** 负责辅助理解和生成
- **系统** 负责自动化
- **人工** 只处理异常
