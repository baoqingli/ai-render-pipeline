## 一、工作流总览

本工作流实现了从**毛坯房照片**到**超写实精装室内效果图**的AI生成，核心思路是：**用 ControlNet 锁定空间结构，用 Lora + IPAdapter 控制风格，用高清放大提升细节**。

整个工作流分为三大模块：

| 模块 | 功能 | 核心节点 |
|------|------|----------|
| 模块一 | 基础生图 | SDXL大模型 + 双ControlNet（轮廓+深度） |
| 模块二 | 风格化 | Lora加载器 + IPAdapter高级应用 |
| 模块三 | 后期放大 | Latent缩放 + 第二阶段K采样器 + VAE解码 |

**最终效果**：毛坯房空间布局还原度约 **95%**，可生成科技前卫、宋式美学、暗黑空间、温暖阳光等多种风格。

## 二、模块一：基础生图（SDXL + 双 ControlNet）

### 2.1 大模型选择

- **节点**：Checkpoint 加载器
- **基础算法**：SDXL（也可选用 SD 1.5）
- **推荐模型**：红潮 Redcraft（建筑设计专用模型）
- **注意**：必须选择与建筑设计相关的模型，否则出图效果会大打折扣

### 2.2 样板图加载（图生图）

1. 删除空 Latent 节点
2. 从 K 采样器的 latent 输入拖出 **VAE 编码器**
3. 添加 **加载图像** 节点，上传毛坯房图片
4. VAE 连接到 Checkpoint

### 2.3 图像缩放节点（关键技巧）

- **节点**：图像缩放（ComfyUI 原生节点，ComfyCore）
- **参数设置**：
  - 宽度 = `1024`
  - 高度 = `0`（表示高度随宽度等比自动缩放）
- **作用**：
  - 统一输入尺寸，避免不同尺寸图片造成工作流崩坏
  - 后续所有节点都从图像缩放节点取图（相当于加载图像的"经纪人"）
- **高手标志**：liblibAI 上的大型工作流几乎都包含图像缩放节点

### 2.4 ControlNet ① — 轮廓保持

| 项目 | 内容 |
|------|------|
| 节点 | ControlNet ADV（旧版高级） |
| 模型 | SAI XL Canny 256 Lora |
| 预处理器 | MLSD 线段预处理器 |
| 强度 | `0.7` |
| 结束时间 | `0.8` |

**为什么选 Canny + MLSD？**
- MLSD 预处理器只保留图片中的**直线**，恰好提取毛坯房的墙体轮廓
- Canny 边缘检测精度高，配合 MLSD 的直线提取非常高效
- Lineart 也可以用，但准确性比 Canny 低

**连接方式**：
- 正面提示词 → ControlNet 正面条件
- 负面提示词 → ControlNet 负面条件
- 图像输入 → MLSD 预处理器 → 图像缩放节点输出
- **注意**：图像必须连到图像缩放节点的输出，不要连原图

### 2.5 ControlNet ② — 空间深度

| 项目 | 内容 |
|------|------|
| 节点 | ControlNet ADV |
| 模型 | SAI XL DeepSD 56 Lora |
| 预处理器 | ZOE（或 Midas，效果都不错） |
| 强度 | `0.4` |

**作用**：保留房间的空间关系和纵深感，确保生成图的空间结构与毛坯房一致。

### 2.6 VAE 全局发散节点（独门秘技）

- **节点**：Anything Everywhere（全局输入）
- **用法**：
  1. 从 Checkpoint 的 VAE 输出拖出 → 搜索 "Anything Everywhere" → 选择全局输入
  2. 断开所有手动连接的 VAE 线
  3. 全局节点像 WiFi 一样把 VAE 信号广播到整个工作流
- **优点**：大幅减少连线数量，工作流更整洁
- **缺点**：报错时可能难以溯源（跟着教程走大概率不会报错）

### 2.7 预览图像节点

在预处理器之后添加 **预览图像** 节点，可以查看预处理后的图像效果（Canny边缘图、深度图等），方便调试。

## 三、模块二：风格化（Lora + IPAdapter 双风格注入）

### 3.1 模型链路（必须按顺序连接）

```
Checkpoint 模型输出
    → Lora 加载器
        → IPAdapter 加载器
            → 应用 IPAdapter 高级
                → K 采样器
```

> 注意：模型输出依次传递，风格逐层叠加，不要连错顺序。

### 3.2 Lora 风格模型

- **节点**：Lora 加载器
- **来源**：liblibAI 模型广场
- **筛选条件**：基础算法选择 **XL**（必须适配 SDXL 底模）
- **可选风格示例**：
  - 科技前卫风格
  - 宋式美学（国韵装修）
  - 暗黑空间
  - 温暖阳光
- **模型强度**：可调（如 0.8）
- **使用方法**：
  1. 在 liblibAI 找到喜欢的 Lora → 加入模型库
  2. 从预览图复制触发词
  3. 回到 ComfyUI 刷新 Lora 列表 → 一键应用
  4. 将触发词粘贴到正面提示词

### 3.3 IPAdapter 风格参考

- **节点**：应用 IPAdapter 高级 + IPAdapter 加载器
- **辅助节点**：CLIP 视觉图像处理（中转站）
- **用法**：
  1. CLIP 视觉图像处理的图像输入 → 加载图像节点
  2. 上传想要参考的**风格效果图**（如东南亚风格、科技感室内图）
  3. AI 会参考该图的风格进行生成
- **特点**：可开关，根据需求取舍

### 3.4 提示词编写技巧

**正面提示词构成**：
```
[Lora触发词] + [质量词汇] + [具体家具/装饰描述]
```

- **质量词汇**：`masterpiece`（杰作）、`best quality`（最高质量）、`highres`（高清晰度）
- **家具描述示例**（宋式美学风格）：中式沙发、中式茶几、中式吊灯、中式落地灯、中式窗户、中式窗帘

**负面提示词**：
- `easynegative v2`（基本够用，也可自行添加更多）

### 3.5 Latent 批次生成（一次出多张）

- **节点**：Latent 批次大小
- **位置**：VAE 编码之后、K 采样器之前
- **参数**：批次大小 = `4`（一次生成4张图挑选）
- **作用**：提高出图效率，从中选择效果最好的一张

## 四、K 采样器（核心生成节点）

| 参数 | 值 |
|------|-----|
| 采样步数 | `30` |
| CFG 值 | `7` |
| 采样器 | `DPM++ 2M` |
| 调度器 | `Karras` |

**输入**：
- 模型：来自 IPAdapter 输出
- 正面/负面条件：来自双 ControlNet
- Latent：来自 VAE 编码（或 Latent 批次）

**输出**：Latent（潜在空间图像）

## 五、模块三：后期高清放大（细节增强）

### 5.1 放大流程

```
K采样器 Latent 输出
    → Latent 按系数缩放
        → K 采样器（第二阶段，复制第一阶段）
            → VAE 解码
                → 预览图像
```

### 5.2 带连线复制技巧（快捷操作）

1. 选中第一阶段的 K 采样器
2. `Ctrl + C` 复制
3. 在空白处按 `Ctrl + Shift + V`（带连线粘贴）
4. 被复制节点的所有连线会自动连接到新节点

> **注意**：此功能仅在部分浏览器中可用（推荐使用 Chrome）。

### 5.3 连接说明

- Latent 按系数缩放的输入 → 第一阶段 K 采样器的 Latent 输出
- Latent 按系数缩放的输出 → 第二阶段 K 采样器的 Latent 输入
- 第二阶段 K 采样器输出 → VAE 解码 → 预览图像
- VAE 无需手动连接，由全局发散节点自动供给

### 5.4 效果

- 放大后茶壶、沙发光泽等细节清晰可见
- 空间结构始终遵循毛坯房布局
- 风格受 Lora + IPAdapter 双重控制

## 六、后期调整技巧

### 通过修改提示词增减元素

- **删除元素**：不想要的家具（如沙发、茶几）→ 从提示词中删去
- **添加元素**：想要的装饰（如屏风）→ 添加对应提示词
- **重新生成**即可看到变化

> 这就是 AI 绘画的灵活性：想咋改就咋改。

## 八、学习建议

1. **先跑通基础流程**：不加 Lora 和 IPAdapter，先用基础生图模块验证空间结构还原
2. **再叠加风格**：逐步添加 Lora 和 IPAdapter，观察风格变化
3. **最后加高清放大**：确认风格满意后再添加放大模块
4. **多换风格测试**：科技前卫、宋式美学、暗黑空间等多试几种，找到最适合的
5. **提示词是关键**：家具描述越具体，生成效果越可控
6. **善用批次生成**：一次出4张，提高挑选效率
