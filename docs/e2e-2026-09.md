## 1. 配置：`.env` 追加两键（硬前提）

```bash
# 追加到仓库根 .env（pydantic-settings 读 ARP_ 前缀）
ARP_PG_DSN=postgresql+psycopg://arp:arp@localhost:5432/arp
ARP_VALKEY_URL=redis://localhost:6379/0
```

不加 `ARP_PG_DSN` 时默认值是裸 `postgresql://...`（无 `+psycopg`），`create_async_engine`
会去解析 psycopg2 方言 → 建引擎即报错。**两处 DSN 写法有差异，勿混用**：

| 消费方 | DSN 写法 | 原因 |
| --- | --- | --- |
| SQLAlchemy `init_pg`（`app/infra/pg.py`） | `postgresql+psycopg://arp:arp@localhost:5432/arp` | 方言后缀选驱动；psycopg 3 同一方言原生支持 asyncio（项目未装 asyncpg/psycopg2，见 pyproject） |
| langgraph `AsyncPostgresSaver.from_conn_string`（§7 生产升级） | `postgresql://arp:arp@localhost:5432/arp` | 直连 psycopg `AsyncConnection`，吃 libpq conninfo——`+psycopg` 后缀会被当未知 scheme 报错 |

`ARP_VALKEY_URL` 两处（API deps 与 runner）共用 `redis://` scheme（valkey 客户端兼容 redis URL）。

## 4. 全流程验收

### 4.1 上传 CAD

  http://localhost:8000/api/projects
# → {"project_id":"<PID>","iteration":1}   记下 <PID>，下同

### 4.2 SSE 事件流（必须 `curl -N`）

```bash
curl -N http://localhost:8000/api/projects/<PID>/events
```

- 帧：`data: {"stage":"...","status":"ok|error","iteration":1}`，空闲 10s 发 `: ping` 注释帧保活。
- **TestClient 缓冲教训（Task 6 台账）**：starlette TestClient（httpx 同步传输）会把
  `StreamingResponse` 整体缓冲，SSE 帧无法逐条到达客户端——单测只能手驱 ASGI 逐段读；
  真机一律 `curl -N`（禁用缓冲）或任何真 uvicorn 客户端。另：`("finalized","ok")` 在失败
  运行也会发布（stage 不判失败，T4 既知）——成功与否以 §4.3 状态接口为准。

### 4.3 轮询状态到 done

```bash
while :; do
  s=$(curl -s http://localhost:8000/api/projects/<PID> \
      | python -c "import sys,json;print(json.load(sys.stdin)['latest']['status'])")
  echo "$(date +%T) latest=$s"; case $s in done|failed) break;; esac; sleep 5
done
```

## 7. PG saver 生产升级（runner 一行切换说明）

代码默认 `InMemorySaver` 是**有意取舍**（离线测试稳定：saver 连接生命周期与测试隔离）。
生产启用 PG 检查点：`app/workers/graph_runner.py` `main()` 中

```python
saver = InMemorySaver()  # e2e 升级点：AsyncPostgresSaver（见 e2e 手册）
```

替换为（`from_conn_string` 是 asynccontextmanager，需包住消费循环；恢复扫描与
`while True` 消费循环整体内移到 `async with` 内）：

```python
from langgraph.checkpoint.postgres.aio import AsyncPostgresSaver
async with AsyncPostgresSaver.from_conn_string(
        "postgresql://arp:arp@localhost:5432/arp") as saver:   # 裸 postgresql://，无 +psycopg（§1 差异表）
    await saver.setup()   # 首次建 checkpoints 系列表（幂等），必须显式调用
    # ↓ 原「恢复扫描 + while True 消费循环」整体内移
```

LANGGRAPH msgpack 注意：检查点序列化走 JsonPlusSerializer（`ormsgpack` C 扩展），
已作为 `langgraph-checkpoint-postgres` 的传递依赖锁进 `uv.lock`（ormsgpack 1.12.2，
Windows/Linux 均有官方 wheel），无需手动安装；若精简依赖导致缺失，import 期即暴露，不会静默。
