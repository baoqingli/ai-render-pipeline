## 图纸定性（修正预侦察判断）

**酒店客房精装/机电综合图**——不是纯建筑平面图。房间名 TEXT（客房/马桶间/盥洗/淋浴间）确认功能分区；图层体系为精装命名（P-家具/C-天花/S-LIGHT/E-插座/C-5消防/GND-地面/CON-标注）。

**关键内容边界：这张图只画"改动墙"**（`P-新砌墙体` 5 段 + `01-原始砖砌筑间隔墙` 1 段 + 隔墙填充 hatch 层），**不含完整建筑外墙/承重墙网**——那是建筑平面图的内容。因此墙中心线网络无法闭合，polygonize 房间数为 0。**这不是解析器 bug，是输入图纸的内容边界**：精装图 ≠ 建筑平面图。

## 五个校准发现（喂给 Phase 3 / 切片 2-3）

1. **【最重要】房间=0 的两类根因要分开处理**：
   a. 图纸无完整墙网（本图情况）→ 需要建筑平面图输入，或 Phase 3 从 `P-完成面`（5 段轮廓线）推断房间边界——精装图的完成面轮廓恰是房间边界的高质量替代源；
   b. 嵌套双环墙形态（Task 5 已知局限）→ 配对算法增强项。
2. **门宽全默认**：真实块名是拼音缩写体系（MS11/MKT），不像语料 `M_门_900` 自带尺寸。Phase 3 的 cad_diagnosis agent 应从块几何 bbox（virtual_entities）量宽度，而不是只从块名正则取数。
3. **家具分类过宽**：117 个"家具"里大量机电点位（喷淋/烟感/扬声器/插座/风口），因分类逻辑是"非门窗 INSERT 全算家具"。修正：按图层白名单（P-固定家具/P-活动家具/FU-/P-洁具）过滤，机电图层（S-/C-5/E-/C-天花）排除。
4. **坐标绝对偏移**（~22万,-37万 mm）：SceneJSON 未归零。切片 2 Blender 工具须做包围盒平移到原点，否则相机/灯光参数全部失真。
5. **窗漏检**：`GL-玻璃窗线` 图层 1 个 INSERT 未进 windows——图层名含"窗"但块名 `$WINLIB2D$00000005` 无中文/英文窗关键词，说明双信号判定在真实命名体系下仍有盲区（需核对 parse.py 中 lw 串的判定条件覆盖）。

**额外发现——置信度与解析质量脱节**：房间 0 但置信度 0.9（inspect 层不知道房间结果）。parse 结果层应叠加解析质量罚分（房间数 0 → 明确低置信度标记），让全自动闭环的降级信号真实可信。
